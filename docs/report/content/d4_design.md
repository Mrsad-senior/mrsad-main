# Software Design Document

This document is deliverable D4 (high-level and low-level design) of the Mirsad senior project. It describes the architecture, components, processes, data design, security design and user-interface design of the system as built. Requirements are specified in the separate D3 Software Requirements Specification.

This document is an extract of the Mirsad Final Report, where its content appears as Section 3.3. Section, figure and table numbers, and references to other sections, chapters and appendices, follow that report.
