# Appendix D – Poster / Presentation Slides

The poster and the final presentation are generated from the project sources by `scripts/build_poster.py` and `scripts/build_slides.py`; both read every measured value from `reports/results_summary.json` at build time, so they always match this report. The editable files are `deliverables/Mirsad_Poster.pptx` (85 cm × 142 cm, the CCIS EXPO format) and `deliverables/Mirsad_Final_Presentation.pptx` (18 slides with speaker notes; the full speaker script is in `docs/presentation_script.md`).
