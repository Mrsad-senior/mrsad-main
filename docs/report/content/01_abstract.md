# Abstract

Large language model (LLM) agents now read e-mail, browse the web and call business tools through the Model Context Protocol (MCP) and OpenAI-style function calling. Any content an agent reads can carry hidden instructions (indirect prompt injection) that turn an authorised agent against its own organisation, and published defences are almost entirely English-centric. This project built Mirsad (مرصاد), a runtime security gateway that sits between an unmodified agent and its tools. Its objectives were to enforce action-level policy with a median overhead of at most 200 ms per call, to detect injected instructions in Arabic and English with an F1 score of at least 0.85, and to keep humans in control while reducing attack success by at least 80% and wrongly blocking no more than 5% of benign actions. Mirsad combines a declarative YAML policy engine, taint tracking of untrusted and confidential data, an Arabic/English injection detector, human approval through an installable bilingual mobile web app, and an HMAC hash-chained audit log with decision replay.
