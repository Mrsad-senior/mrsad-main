# Mirsad Software User Guide

This guide is deliverable D6 of the Mirsad senior project. It explains how to install, configure, operate and integrate Mirsad, for administrators, approvers and agent developers.

This document is an extract of the Mirsad Final Report, where its content appears as Appendix E. Section, figure and table numbers, and references to other sections, chapters and appendices, follow that report.
